# 自制小游戏视觉升级验收

日期：2026-09-29。范围：署名“杨老师玩AI · AI 生成”的六款游戏。

## 已完成

- 锦鲤消消：原创池塘场景、六色锦鲤瓷片、交换动画、消除光点、滑动交换；保留点击交换、提示和计分。
- 夜市叠箱：灯会夜景、木框棋盘、有木纹与铆钉的货箱、消行动效；保留七种方块、落点预览与暂停。
- 灯会翻牌：灯笼卡背、纸质卡面、配对亮灯和进度；最后一对翻开后再显示结果。
- 夜市冲刺：灯会场景、前景灯笼和路面；修复角色跳跃时绘制仍停在地面的错误。
- 纸飞机防线：小城晴空、折纸阴影和折痕，保留拖动、按键与六波战斗。
- 雨巷书摊：雨夜背景、旧书纸页、章节进度、选择反馈，保留原有分支与结局。
- 六款统一开始与结果面板，增加可关闭的合成音效；默认静音，支持减少动态效果设置。
- 目录页增加对应场景预览；图片内嵌于各自 HTML，单文件离线打开方式保留。

## 本地验证

使用 Windows 上的 Microsoft Edge，通过 Playwright 操作。全部使用 `file://` 地址，并将浏览器网络设为离线。

- 1440×1000、390×844：六款均能从开始面板进入游戏，场景显示正常，无页面脚本错误、无横向溢出。
- 320、768 像素宽度：六款均无横向溢出。
- 共 44 项操作与界面检查通过：启动焦点恢复、锦鲤提示/点击/滑动/无效交换/重开、翻牌匹配/不匹配/八对通关/重开、木箱移动/旋转/落底/暂停/消行、跑酷跳跃位置与绘制位置一致/滑行/松开恢复、飞机键盘/拖动/自动发射、文字冒险结局/重开、音效开关、减少动态效果。
- 截图检查覆盖六款桌面和手机宽度界面，并检查翻牌配对后的显示。`git diff --check` 用于发布前格式检查。

## 范围说明

手机验证使用浏览器触控与窄屏模拟，没有覆盖真实 iOS/Android 设备。未穷举所有随机棋局、战斗波次和故事分支。音效开关与合成逻辑已运行，未做扬声器听感验收。
