先玩一局原创测试游戏

点击“开始游戏”或按 Enter。方向键移动，A（J）开启短暂护盾并冻结巡逻机，B（K）加速。收集 12 枚星晶获胜，被撞 3 次失败。游戏由页面内置的 starborne.nes 执行，可单独导出。

插入自己的游戏

点击“插入卡带”或把 .nes 文件拖到页面。当前不接受 ZIP、GBA、NDS、PSP 或 FDS 文件。只使用你有权使用的游戏文件；包内不附商业游戏。遇到不兼容提示，可在设置中尝试 JSNES 标准核心，需要联网加载，切换会重启当前游戏。

本地保存与兼容范围

3 个即时存档按 ROM 指纹和核心隔离，支持 JSON 导出与恢复。启用电池存档的 ROM 会尽力保存 SRAM。文件:// 地址下的浏览器储存策略因浏览器而异；重要进度请导出。切到后台会自动暂停，避免丢命或持续发声。

内置 RoomNES 0.1 支持 Mapper 0 / 1 / 2 / 3 / 4 / 7 / 11 / 66 / 71 的基础映射，采用指令级 CPU 和扫描线图像实现。高级图形时序、特殊外设、PAL 与 NES 2.0 不在本版验证范围。JSNES 为可选独立开源核心，存档不与内置核心互通。

这台机器由什么组成

原生 WebGL 三维电视、主机、卡带和手柄；WebGL 不可用时以 Canvas 投影相同三维模型；独立模拟核心；Web Audio 音频；本地文件读取与 IndexedDB 存档。没有登录、广告、遥测或游戏上传。不是实体 FC 的固件，也不是 GBA / NDS 通用模拟器。
