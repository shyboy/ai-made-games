# AI 游戏收录

收录 AI 参与制作的网页版和单机版游戏，按玩法分组，方便找想玩的类型。当前共有 **38 个游戏条目**：13 个 HTML 游戏保存在本仓库，可以在线玩或下载；25 个外部条目提供原作者的试玩或获取地址。

**[打开可视化游戏目录](https://shyboy.github.io/ai-made-games/)**

## 仓库内的游戏

这 13 款均为单文件 HTML，点击“开始游戏”可在线玩，也可下载文件在电脑上打开。其中 6 款由杨老师提供，作者署名为微信昵称 **朱斌**；收录时只将文件改名为各目录下的 `index.html`，未修改游戏内容。另 6 款署名为 **杨老师玩AI · AI 生成**。《SWARM》署名原作者 **Nerabwyn**，单独采用 MIT 许可。

我把自己做的 6 款小游戏重新打磨了一遍：《锦鲤消消》换上锦鲤池和瓷片棋子，《夜市叠箱》《灯会翻牌》加入灯火夜景、木箱与花灯卡面，其余三款也更新了场景和界面。图片已嵌入 HTML，下载后仍可直接打开；音效默认关闭，可在游戏内开启。

### 游玩前说明

- **需要本地运行**：《天际5》按原仓库说明启动，尚无已核实的在线试玩地址；《街机口袋》需 Node.js 20 或更新版本，运行 `node server.mjs`。
- **加载与访问**：《修仙掌门生涯》首次加载可能较慢；两则 Spy Hunter 试玩偶发人机验证。
- **语言与时长**：《100 Games》《LittleJS Arcade》《EPOCH》和 Spy Hunter 为英文界面；《Clauding》界面英文、帮助含中文，《Clawd Arcade》为中英双语，《hollowlullaby》为中文作品集。《归零协议》单局约二三十分钟。
- **版本与同人**：《晴湾防线无尽版》《棱镜交火》《象棋》与《晴湾防线》同属 iiduce 的游戏站，无尽版难度更高。《穿越火线》《QQ 飞车》《黑神话：悟空》《天际5》《Spy Hunter》相关条目为非官方同人或致敬作品，与原游戏厂商无关。

## 署名与使用

仓库内游戏未收到统一的再使用许可，因此本仓库不附加统一的开源许可证。《SWARM》单独附有原作者的 [MIT 许可](games/swarm/LICENSE)，署名仍为 Nerabwyn。游戏与商标的权利归各自权利人；收录不代表可任意复制或商用。署名或链接需要更正时，请提交 Issue。
