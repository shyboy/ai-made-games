# AI 游戏收录

收录用 AI 制作的网页版和单机版游戏。这里有可直接打开的网页文件，也有指向原作者网站的游戏链接。

**[打开游戏目录，直接游玩](https://shyboy.github.io/ai-made-games/)**

## 提交新游戏

欢迎把用 AI 制作的游戏发给我。扫码添加微信时请备注「AI 游戏投稿」，并附上游戏名称、可玩或下载地址、作者署名，以及是否允许本仓库托管游戏文件。我核对后会更新收录。
